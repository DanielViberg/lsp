## Detailed description 

The Diagnostic sign_place call in lib/Features/Diagnostics.vim at line
157 always uses ID 1: `sign_place(1, 's_g', 's_' .. type, buf, {lnum:
line})`.

In Vim's sign system, the ID parameter must be unique per sign. Using ID
1 for all signs means only one diagnostic sign can be displayed per
buffer at a time. Each new diagnostic overwrites the previous one, so
only the last placed sign is visible.

When a file has multiple diagnostics, only the final one will show its
sign. All earlier diagnostics are invisible. The fix should use a
unique ID per diagnostic, such as an incrementing counter or the
diagnostic's index in the list.
