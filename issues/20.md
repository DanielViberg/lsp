## Detailed description 

The RpcSync() function in lib/Rpc/Rpc.vim at line 25 uses
`server.job->ch_evalexpr(request)` which is a synchronous blocking call.

This freezes Vim's UI thread while waiting for the LSP server's
response. Functions like HoverCmd(), Format(), and ResolveCompletion()
all use RpcSync, causing noticeable UI freezes during:
- Hover tooltip display
- Document formatting on save
- Completion item resolution

For a responsive editor experience, these operations should use async
patterns with callbacks. The async counterpart RpcAsync() exists but is
not used by these features. Converting these to async would eliminate
UI freezes and provide a smoother editing experience, especially on
slow servers or large files.
