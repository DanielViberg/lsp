## Detailed description 

The RequestMessage.ToJson() method in
lib/Protocol/Abstracts/RequestMessage.vim hardcodes the request ID to 0:
`return { id: 0, method: this.method, params: this.params }`.

It should be `{ id: this.id, ... }` to serialize the actual request ID
set by RpcAsync/RpcSync before calling ToJson(). With the hardcoded 0,
all requests sent to the language server have ID 0.

This means the language server cannot properly match responses to their
corresponding requests. If multiple requests are in flight simultaneously,
responses will be misrouted or lost entirely. This can cause features
like completion, hover, and go-to-definition to fail or return stale
data.
