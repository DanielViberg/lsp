## Detailed description 

The Server.Kill() method in lib/ClientState/Server.vim sends an 'exit'
notification to the server but never actually terminates the server
process.

The method does not call `job_stop()` on the job object, does not set
`isRunning = false`, and does not perform any cleanup. Compare this with
the Stop() method which properly terminates the job.

If Kill() is called (e.g., for ungraceful shutdown or emergency
termination), the server process will continue running as an orphan
process. This wastes system resources and can cause port conflicts or
file lock issues when trying to restart the server.
