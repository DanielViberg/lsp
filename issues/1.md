## Detailed description 

The Enable() function in plugin/lsp.vim at line 46 sets `buf.disable =
true`, which is the opposite of what it should do. When a user calls
`:LspEnable` to re-enable the plugin after having disabled it, this line
sets the disable flag to true, effectively keeping the plugin disabled.

The Disable() function at line 39 correctly sets `buf.disable = true` to
disable the buffer. However, Enable() should set `buf.disable = false` to
re-enable it. This is a clear logic bug where the wrong boolean value is
assigned.

As a result, once a buffer is disabled via :LspDisable, there is no way to
re-enable it through the :LspEnable command. The plugin will remain
disabled for that buffer for the entire session.
