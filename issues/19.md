## Detailed description 

The bufferWords variable in lib/Features/Completion.vim is a
module-level global list shared across ALL buffers. When
CacheBufferWords() is called (triggered by BufEnter, InsertEnter, etc.),
it adds words from the current buffer to this shared list.

Words from all open buffers accumulate in this single list. This means:
- Completion suggestions from one file appear in all files
- Unrelated code from different projects pollutes completions
- The cache limit (g:lsp_comp_buf_cache_limit) is shared globally
- Memory grows unbounded as more buffers are opened

The bufferWords cache should be scoped per buffer, using a dictionary
mapped by buffer ID. This would ensure completions are relevant to the
current file and memory usage stays bounded.
