## Detailed description 

In lib/Features/DocumentSync.vim, the DidOpen() function calls
`listener_add()` for each server, creating one listener per
server-buffer pair. However, DidClose() calls
`listener_remove(bId)` which removes ALL listeners for that buffer,
regardless of which server initiated the close.

When one server is stopped while others are still active for the same
buffer, the listeners for remaining servers are also removed. This breaks
document synchronization for the still-active servers, causing them to
stop receiving buffer change events.

This is particularly problematic in multi-server setups where different
servers handle different language features. Stopping one server can
silently break features provided by other servers on the same buffer.
