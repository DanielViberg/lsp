## Detailed description 

The WillSaveTextDocument notification in
lib/Protocol/Notifications/WillSaveTextDocument.vim sends malformed LSP
parameters.

According to the LSP specification, `textDocument/willSave` params must
include a `textDocument` object with a `uri` property: `{ textDocument:
{ uri: uri }, reason: reason }`. The current implementation sets
`textDocument: uri` (a raw string) instead of `textDocument: { uri: uri
}` (an object containing the uri).

This is a protocol violation. Language servers that strictly follow the
LSP specification will reject or misinterpret this notification. This
could cause willSave handlers on the server side to fail, breaking
features that depend on pre-save hooks like document formatting or
validation.
