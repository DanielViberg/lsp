*lsp.txt*	Vim 9 Language Server Protocol Client

==============================================================================
SETTINGS							  *lsp-settings*

g:lsp_format_pre_save (bool)				   *lsp_format_pre_save*
Perform lsp format on buffer pre write.

g:lsp_autocomplete (bool)				      *lsp_autocomplete*
Autocomplete when writing.

g:lsp_comp_buf_cache_limit (bool)		      *lsp_comp_buf_cache_limit*
How many buffer words are allowed to be cached

g:lsp_diagnostics (bool)				       *lsp_diagnostics*
Show lsp diagnostic.

==============================================================================
CONFIGURATION                                                *lsp-configuration*

Example configuration of a server in the lsp-config.json:

{
  "name": "phpls",	      # (Required) A name of the lsp server, needs to 
			      # be unique.
  "filetype": ["php"],	      # (Required) The filetype for this server.
  "path": "/usr/local/php",   # (Required) Path to server binary.
  "args": ["--stdio"]	      # (Optional) Server arguments.
  "workspaceConfig": {}	      # (Optional) Workspace configuration for this 
			      # server
  "initializationOptions": {} # (Optional) Server specific options
}

==============================================================================
COMMANDS                                                          *lsp-commands*

*:LspConfig*
Open the global lsp configuration file.

*:LspRestart*
Restart the language server.

*:LspDisable*
Disable the language server.

*:LspEnable*
Enable the language server.

*:LspFormat*
Format current buffer.

*:LspGoToDefinition*
Go to definition of symbol under cursor.

*:LspDiagnostics*
Check solution-wide diagnostics using the language servers associated with open
file buffers, including hidden buffers. Each server is queried once. Servers
without workspace-diagnostic support are skipped.

Results include unopened files and all severities: error, warning, information,
and hint. They appear in the quickfix window with abbreviated solution-relative
directory names, the full filename, severity, message, and line/column:
>
    "s/S/AccountService.cs" error: Unknown identifier (42:9)
<
Use <Enter>, :cnext, or :cprevious to jump to an issue. The shortened paths are
only for display; navigation uses the full file path and diagnostic position.

Checks run asynchronously. Run the command again to refresh results. Empty
reports clear resolved issues. Failed requests or a two-minute timeout mark
the list as incomplete; successfully returned results remain available.
